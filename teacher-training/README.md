# Tababarka Macallimiinta Xirfadlaha ah

**Xafiiska Waxbarashada Dowlada Deegaanka Soomaalida · Somali Regional State Education Bureau**

Barnaamij tababar oo **offline** ah oo loogu talagalay macallimiinta fasalada 1–8 ee **gobollada Dowlada Deegaanka Soomaalida oo dhan**.

## Sida loo isticmaalo
1. Fur `SREB_Teacher_Training_Platform.html` (Chrome, Edge ama Firefox). Internet looma baahna.
2. Macallinku wuu is-diiwaangeliyaa, kadibna wuxuu akhriyaa casharrada, ku tababarta su'aalaha, qaataa imtixaanka cutub kasta.
3. Kadib 7-da cutub iyo imtixaanka dhammaadka, macallinku wuxuu helaa shahaado leh QR code iyo koodh xaqiijin.
4. Xogtu waxay ku kaydsantaa kombiyuutarka. Maamulaha: **Maamul → Kaydin** si loo soo saaro kaydin (JSON) ama CSV.

Furaha maamulaha ee caadiga ah: `admin123`. Ka beddel **Maamul → Habaynta**.

## Cutubyada
1. Macallinka Xirfadlaha ah
2. Hababka iyo Farsamooyinka Waxbaridda
3. Maaraynta iyo Habaynta Fasalka
4. Qorsheynta Casharka iyo Micro-teaching
5. Qiimaynta Barashada
6. Guusha Arday Kasta *(cusub)*
7. Horumarka Xirfadeed iyo Bulshada *(cusub)*

Cashar kasta: fikradda muhiimka ah · qodobo · tusaale deegaanka ah · "Isku day berri".

## Waxyaabaha muhiimka ah
- Isku-dayga imtixaanka xad ma leh. Imtixaanka kadib macallinku wuxuu arkaa jawaabaha saxda ah iyo sharraxaad.
- Su'aalo tababar (waqti la'aan, jawaab deg deg ah) cutub kasta.
- Qalabka Macallinka: 10-ka xeer, liiska maalinlaha ah, su'aalaha milicsiga, foomka qorshaha casharka (la daabici karo).
- Shahaado A4 landscape ah. Tusaale: `Tusaale_Shahaado_Sample_Certificate.pdf`.
- Daabacaadda shahaadada: dooro **Landscape** oo shid **Background graphics**.
