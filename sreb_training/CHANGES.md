# SREB Teacher Training — v4.1 changes

Additions only; the rest of v4.0 is unchanged.

- **Personal password:** each teacher sets their own password when they register. Signing in needs the name and that password. The common college password is still required to register. Devices registered under v4.0 keep using the common password.
- **Admin:** a new "Set new teacher password" button. It changes the password only; the name stays the same.
- **One name, one certificate:** the name, college, department and level are frozen into the certificate when it is issued. A different name cannot open or take over that certificate. If the same name earns a certificate again, it gets back the original certificate and number.
- **Certificate No.:** the number now appears in a box at the top right of the certificate.
- **QR:** the code now holds readable text (No / Name / College / Dept / Level / Score / Date / Code), so any camera app shows the details. The verify page has a new camera-scan button (Chrome on Android). Older `SREB1|…` QR codes still verify.
